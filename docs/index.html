CausalLayer Anchor Verifier

Independently verify a CausalLayer signed anchor or attribution certificate directly in your browser. This page makes no network calls to CausalLayer after the public key is loaded from this same GitHub Pages origin.

Open source. View the source of this page at any time with View Source, or read it on GitHub. Verification uses the W3C Web Cryptography API (Ed25519, RFC 8032; SHA-256, FIPS 180-4).

What this page verifies, and what it does not

    

      

        
This page verifies

        
    
          
  • The Ed25519 signature over the canonical body of an anchor or certificate.
    • 
          
  • That the signing key's fingerprint matches the canonical key published in this same repository.
    • 
          
  • For anchors: that the published Merkle root recomputes from the leaves.
    • 
          
  • That the authoritative flag is true and the algorithm is ed25519 (not a dev-only HMAC mode).
    • 
        

      

      

        
This page does not

        
    
          
  • Verify the OpenTimestamps Bitcoin proof — use the
            opentimestamps-client
            against the .ots file.
    • 
          
  • Validate the substance of an attribution. Cryptographic verification ≠ correctness of fault allocation.
    • 
          
  • Confirm the key has not been compromised after signing. That's a separate
            SECURITY policy concern.
    • 
        

      

    


    

      
Pre-genesis status (as of 2026-05-14).

      

        At the time of writing, the public anchor log contains the canonical public
        key, fingerprint, key-rotation post-mortem, and verifier, but
        no authoritative anchors have been signed yet. The first
        authoritative anchor will close the genesis period. You can still exercise
        this page using the “Load example (dev-test)” button, which loads
        an anchor signed by a clearly-labelled development key whose
        fingerprint does not match production. Dev-test anchors are
        not evidentiary and the result panel will say so.
